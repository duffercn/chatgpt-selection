# ChatCopy Privacy Policy
Updated: November 10, 2026

ChatCopy helps you copy the current saved conversation from supported AI chat websites so you can paste it elsewhere. Some sites use their own native copy or TXT-export controls.

### Data handled
When you request a copy, the extension handles the current conversation's text, message roles, order, conversation identifiers and available supported attachment metadata. A conversation may contain personal information that you or the chat provider included. The extension also uses the current supported tab's URL to identify the platform and conversation. It does not inspect unrelated browsing history, collect keystrokes, or read your system clipboard.

API adapters use your existing signed-in session to request conversation data from that same provider over HTTPS. Gemini additionally requires temporary authentication metadata from its signed-in page. This metadata is used in memory for the provider request and is not logged or stored by the extension. You do not provide account passwords to the extension. Native wrappers operate the website's copy/export controls.

### Local processing and sharing
Conversation content is processed locally in the browser and written to your local clipboard when copying succeeds. Qwen Global's native flow instead downloads a TXT file. ChatCopy does not run a backend that receives conversation data, upload conversations to the developer or an unrelated service, sell data, use it for advertising or credit decisions, or include analytics. It does not execute remotely hosted code.

Requests to your selected chat provider remain subject to that provider's terms and privacy practices. If you paste a transcript into another chatbot or app, you choose that destination and its own privacy practices apply.

### Retention and control
The extension does not maintain a conversation archive, persist authentication metadata, or sync conversation data to a developer service. Temporary data is used to complete the requested copy. Chrome, your operating system, your clipboard manager and native downloaded files may retain the result according to their own settings. You can replace or clear your clipboard, remove exported files, disable site access, or uninstall the extension through Chrome.

### Limited use
ChatCopy uses the user data it handles only to provide its described conversation-copy/export functionality. Its use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. It does not sell user data, use it for unrelated purposes, or use it to determine creditworthiness.
